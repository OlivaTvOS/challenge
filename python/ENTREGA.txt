Projeto
SoulUp - sustentabilidade e missões

Explicação
O programa Python usa a API Java para manter os dados do projeto compartilhados com o sistema web. O menu oferece cadastro e acesso ao perfil e permite consultar, alterar e excluir os dados da conta. Também permite consultar e realizar missões e visualizar o ranking.

As funções organizam os registros recebidos em listas de dicionários, exibem os dados e filtram uma missão pelo identificador informado. As consultas de perfil e missões podem ser exportadas para JSON. O programa também consome a API pública Open-Meteo para consultar temperatura e precipitação, informações úteis para planejar atividades ao ar livre.
